# Güvenlik

Konu ve tekrar kayıtları yalnızca tarayıcı `localStorage` alanındadır. Uygulama parola veya uzaktan eşitleme sağlamaz. Paylaşılan cihazlarda kişisel not girmeyin. Kullanıcı metni ekrana basılmadan önce HTML karakterleri kaçışlanır.

Güvenlik bildirimlerini herkese açık issue yerine profilimdeki e-posta adresine iletebilirsiniz.
